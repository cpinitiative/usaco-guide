## Explanation

We can use binary search on our answer to calculate the maximum
median salary possible. Let's first understand that for `mid` to 
be the median salary, we need to verify if it is possible to assign 
`mid` dollars in salaries to at least $\lceil \frac{n}{2} \rceil$ 
employees while also keeping the budget under $s$ dollars.

Since we want to maximize our median salary, we need to raise as 
many employees' salaries to `mid` as possible while still staying 
within budget. Firstly, we will prioritize those employees whose 
salary $l_i$ is already close to `mid`, since they will require 
less extra cost to reach `mid`. Among all employees who are capable 
of earning at least `mid` (i.e. $r_i \geq$ `mid`), we will 
greedily pick the $\lceil \frac{n}{2} \rceil$ cheapest ones to 
raise to `mid`.

For `mid` to be attainable, we will first collect all those 
employees who earn at least `mid` salary (note that if the number 
of such employees is less than $\lceil \frac{n}{2} \rceil$, then 
`mid` is not achievable since we cannot assign at least `mid` 
salary to enough employees). For each such employee, the extra cost 
to increase their salary to `mid` will be $\max(0, mid - l_i)$. 
We will store these values in an array for further use.

Now, we will sort the extra cost values that we stored previously 
and greedily pick the $\lceil \frac{n}{2} \rceil$ cheapest ones, 
since we want to maximize our median salary while managing the 
budget under $s$ dollars. If the $\lceil \frac{n}{2} \rceil$ extra 
cost values plus the sum of all minimum salaries stay within the 
budget, then `mid` is achievable.


## Implementation

**Time Complexity:** $\mathcal{O}(N \log N \log (\max r_i))$

```cpp
#include <algorithm>
#include <iostream>
#include <numeric>
#include <vector>

int main() {
	int test_num;
	std::cin >> test_num;

	for (int t = 0; t < test_num; t++) {

		int n;
		long long s;
		std::cin >> n >> s;
		std::vector<std::pair<int, int>> arr(n);
		long long lower_sum = 0;

		for (auto &[l, r] : arr) {
			std::cin >> l >> r;
			lower_sum += l;
		}

		auto is_possible = [&](int mid) {
			std::vector<int> p;
			for (int i = 0; i < n; i++) {
				if (arr[i].second >= mid) {
					p.push_back(std::max(0, mid - arr[i].first));
				}
			}

			std::sort(begin(p), end(p));

			if ((int)p.size() >= (n + 1) / 2) {
				long long req_sum =
				    std::accumulate(begin(p), begin(p) + (n + 1) / 2, 0LL);
				return (req_sum + lower_sum <= s);
			} else {
				return false;
			}
		};

		int lo = 0, hi = 1e9;

		while (lo < hi) {
			int mid = (lo + hi + 1) / 2;
			if (is_possible(mid)) {
				lo = mid;
			} else {
				hi = mid - 1;
			}
		}

		std::cout << lo << '\n';
	}
}
```
