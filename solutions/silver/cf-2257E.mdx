## Explanation

It is helpful to focus on one building, project $k$ to make the highest, and only using the rest of the projects to get additional carrots.
Since we may be able to get more carrots from the first layers of building $k$ as well, we could first get as many carrots as possible from all buildings before trying possible $k$'s to buikd even higher.

To get carrots from working on project $i$ that already has $j_1$ floors built, we must build to a floor $j_2$ such that
$$\text{Profit}=\sum_{j=j_1+1}^{j_2}(b_{i,j}-a_{i,j}) > 0$$
in order to be profitable.  We should always build to the smallest $j_2$ that satisfies this, as building to a larger $j_2$ may actually decrease the profit.
Since we can never have a negative amount of carrots in stock, this requires at least
$$-\min_{j_0=j_1}^{j_2-1}\left(\sum_{j=j_1+1}^{j_0}b_{i,j}-a_{i,j}\right)-a_{j_0+1}$$
carrots - the opposite minimum difference between any number of carrots reached during the builds.
The minimum $j_2$, the required cost, and the gained profit are all readibly computable for the current floors built of a project by iterating $j_1\dots j_2$ once, with the gained profit maintained using a prefix-sum-like approach.

As building a range of floors only ever increases the number of carrots we have, it is optimal to build any range of floors satisfying the above that we can build with our current carrots.
Thus, we maintain a min-heap to track all possible ranges sorted by required cost to build across projects.
In particular, we:

1. Initialize the min-heap with all buildable ranges (tracking required cost, profit, project number, and ending floor) with $j_1=0$ across all projects.
2. Repeatedly build the range with the smallest required cost if possible; if required cost is larger than current carrots, then no more ranges are buildable, and we stop.
3. After building the range, compute the next range for the same project, and add it to the min-heap.

When we have exhausted the possibility to build any more ranges, we now use all of the carrots we have gained on a singular project.
It suffices to enumerate through every project afterwards, and to build as much new layers as possible using our carrots.
The answer is simply the highest building we could build across all projects.
