## Explanation

We want to insert characters into the DNA string $S$ so that the gene $G$ appears as a contiguous substring. Each inserted character costs $\operatorname{cost}(c)$.

The key observation is that the original DNA characters inside the matching window form one **contiguous block** $S[l..r]$. Since their order cannot change, this block must be a **subsequence** of $G$.

Instead of minimizing the insertion cost directly, start by inserting all of $G$. Every DNA character we match saves its insertion cost. Thus,

$$
\text{answer}=\text{total cost of }G-\text{maximum saved cost}.
$$

The input gives the four insertion costs in the order $A,C,G,T$.

### Solution 1: Greedy (Two Pointers)

Fix the starting position $l$. Because all costs are non-negative, extending $S[l..r]$ can only increase the saved cost. Therefore, for each $l$, we only need the **longest prefix** $S[l..r]$ that is a subsequence of $G$.

We greedily match each DNA character to the earliest possible position in $G$. To find that position quickly, precompute $\text{nxt}[c][p]$, the first position at or after $p$ containing character $c$.

For every starting position $l$:

1. Start at the beginning of $G$.
2. Extend the DNA block while its characters can be matched as a subsequence of $G$.
3. Add each matched character's cost to the saved cost.
4. Keep the maximum saved cost over all $l$.

Every valid matching window corresponds to some contiguous DNA block, and for a fixed start the longest valid block saves at least as much as any shorter one.

### Implementation

**Time Complexity:** $\mathcal O(NM)$

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(nullptr);

	string dna, gene;
	cin >> dna >> gene;

	// the insertion costs in the order A, C, G, T
	long long cost[4];
	for (int i = 0; i < 4; i++) { cin >> cost[i]; }

	auto id = [](char ch) -> int {
		switch (ch) {
		case 'A':
			return 0;
		case 'C':
			return 1;
		case 'G':
			return 2;
		case 'T':
			return 3;
		default:
			return -1;
		}
	};

	int n = (int)dna.size();
	int m = (int)gene.size();

	// total = cost of inserting every character of the gene
	long long total = 0;
	for (char ch : gene) { total += cost[id(ch)]; }

	// nxt[c][p] = first gene position >= p containing character c, or m if none
	vector<vector<int>> nxt(4, vector<int>(m + 1, m));
	for (int c = 0; c < 4; c++) {
		for (int p = m - 1; p >= 0; p--) {
			nxt[c][p] = nxt[c][p + 1];
			if (id(gene[p]) == c) { nxt[c][p] = p; }
		}
	}

	// best = the most insertion cost we can save by matching DNA to the gene
	long long best = 0;
	for (int l = 0; l < n; l++) {
		// greedily extend the block dna[l..r] while it stays a subsequence
		int pos = 0;  // the next gene position we are allowed to match
		long long saved = 0;
		for (int r = l; r < n; r++) {
			int q = nxt[id(dna[r])][pos];
			if (q == m) { break; }
			pos = q + 1;
			saved += cost[id(dna[r])];
		}
		best = max(best, saved);
	}

	cout << total - best << '\n';

	return 0;
}
```

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class GMO {
	private static int id(char ch) {
		switch (ch) {
		case 'A':
			return 0;
		case 'C':
			return 1;
		case 'G':
			return 2;
		case 'T':
			return 3;
		default:
			return -1;
		}
	}

	public static void main(String[] args) throws IOException {
		BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
		String dna = br.readLine().trim();
		String gene = br.readLine().trim();

		StringTokenizer st = new StringTokenizer(br.readLine());
		long[] cost = new long[4];
		for (int i = 0; i < 4; i++) { cost[i] = Long.parseLong(st.nextToken()); }

		int n = dna.length();
		int m = gene.length();

		// total = cost of inserting every character of the gene
		long total = 0;
		for (int j = 0; j < m; j++) { total += cost[id(gene.charAt(j))]; }

		// nxt[c][p] = first gene position >= p containing character c, or m
		int[][] nxt = new int[4][m + 1];
		for (int c = 0; c < 4; c++) {
			nxt[c][m] = m;
			for (int p = m - 1; p >= 0; p--) {
				nxt[c][p] = nxt[c][p + 1];
				if (id(gene.charAt(p)) == c) { nxt[c][p] = p; }
			}
		}

		// best = the most insertion cost we can save by matching DNA to the gene
		long best = 0;
		for (int l = 0; l < n; l++) {
			// greedily extend the block dna[l..r] while it stays a subsequence
			int pos = 0;  // the next gene position we are allowed to match
			long saved = 0;
			for (int r = l; r < n; r++) {
				int q = nxt[id(dna.charAt(r))][pos];
				if (q == m) { break; }
				pos = q + 1;
				saved += cost[id(dna.charAt(r))];
			}
			best = Math.max(best, saved);
		}

		System.out.println(total - best);
	}
}
```

### Solution 2: Dynamic Programming

<Info >
Note: Dynamic Programming is not in the Bronze Module.
</Info>

Let $f(i,j)$ be the minimum insertion cost when a contiguous DNA block ends at $S[i]$ and $S[i]$ is matched to $G[j-1]$.

Let $\operatorname{pre}[j]$ be the cost of inserting the first $j$ characters of $G$, and let $\operatorname{suf}[j]$ be the cost of inserting $G[j..M-1]$.

If $S[i]=G[j-1]$, the block either starts at $S[i]$ or extends the block ending at $S[i-1]$. This gives

$$
f(i,j)=\operatorname{pre}[j-2]
+\min\left(0,
\min_{\substack{1\le p<j\\S[i-1]=G[p-1]}}
\left(f(i-1,p)-\operatorname{pre}[p-1]\right)\right).
$$

The inner minimum can be maintained with a running minimum as $j$ increases, so each state takes $\mathcal O(1)$ time.

The answer is

$$
\min\left(\operatorname{suf}[0],
\min_{i,j}\left(f(i,j)+\operatorname{suf}[j]\right)\right).
$$

Only the previous DP row is needed.

### Implementation

**Time Complexity:** $\mathcal O(NM)$

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(nullptr);

	string dna, gene;
	cin >> dna >> gene;

	long long cost_a, cost_c, cost_g, cost_t;
	cin >> cost_a >> cost_c >> cost_g >> cost_t;

	auto cost_of_char = [&](char ch) -> long long {
		switch (ch) {
		case 'A':
			return cost_a;
		case 'C':
			return cost_c;
		case 'G':
			return cost_g;
		case 'T':
			return cost_t;
		default:
			return (long long)1e18;
		}
	};

	int n = (int)dna.size();
	int m = (int)gene.size();

	// pre[j] = cost of inserting the first j gene characters
	vector<long long> pre(m);
	for (int j = 0; j < m; j++) {
		pre[j] = (j ? pre[j - 1] : 0) + cost_of_char(gene[j]);
	}
	// suf[j] = cost of inserting gene characters gene[j..m-1]
	vector<long long> suf(m + 1, 0);
	for (int j = m - 1; j >= 0; j--) { suf[j] = suf[j + 1] + cost_of_char(gene[j]); }

	const long long INF = (long long)1e18;
	long long ans = suf[0];  // insert the entire gene

	// prevE[p] = f(i-1, p) - pre[p-1], for p = 1..m
	vector<long long> prevE(m + 1, INF);

	for (int i = 0; i < n; i++) {
		char prev_char = (i == 0 ? '\0' : dna[i - 1]);

		// running min of prevE[p] over p < j with gene[p-1] == dna[i-1]
		long long run = INF;
		vector<long long> curE(m + 1, INF);

		for (int j = 1; j <= m; j++) {
			if (prev_char && j >= 2 && gene[j - 2] == prev_char) {
				run = min(run, prevE[j - 1]);
			}
			if (dna[i] != gene[j - 1]) continue;

			long long insert_prefix = (j >= 2 ? pre[j - 2] : 0);
			long long f = insert_prefix + min(0LL, run);
			curE[j] = f - pre[j - 1];
			ans = min(ans, f + suf[j]);
		}

		prevE.swap(curE);
	}

	cout << ans << '\n';

	return 0;
}
```

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.Arrays;
import java.util.StringTokenizer;

public class GMO {
	private static long costOf(char ch, long costA, long costC, long costG,
	                           long costT) {
		switch (ch) {
		case 'A':
			return costA;
		case 'C':
			return costC;
		case 'G':
			return costG;
		case 'T':
			return costT;
		default:
			return (long)1e18;
		}
	}

	public static void main(String[] args) throws IOException {
		BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
		String dna = br.readLine().trim();
		String gene = br.readLine().trim();

		StringTokenizer st = new StringTokenizer(br.readLine());
		long costA = Long.parseLong(st.nextToken());
		long costC = Long.parseLong(st.nextToken());
		long costG = Long.parseLong(st.nextToken());
		long costT = Long.parseLong(st.nextToken());

		int n = dna.length();
		int m = gene.length();
		final long INF = (long)1e18;

		// pre[j] = cost of inserting the first j gene characters
		long[] pre = new long[m];
		for (int j = 0; j < m; j++) {
			pre[j] = (j > 0 ? pre[j - 1] : 0) +
			         costOf(gene.charAt(j), costA, costC, costG, costT);
		}
		// suf[j] = cost of inserting gene characters gene[j..m-1]
		long[] suf = new long[m + 1];
		for (int j = m - 1; j >= 0; j--) {
			suf[j] = suf[j + 1] + costOf(gene.charAt(j), costA, costC, costG, costT);
		}

		long ans = suf[0];  // insert the entire gene

		// prevE[p] = f(i-1, p) - pre[p-1], for p = 1..m
		long[] prevE = new long[m + 1];
		Arrays.fill(prevE, INF);

		for (int i = 0; i < n; i++) {
			char prevChar = (i == 0 ? '\0' : dna.charAt(i - 1));

			// running min of prevE[p] over p < j with gene[p-1] == dna[i-1]
			long run = INF;
			long[] curE = new long[m + 1];
			Arrays.fill(curE, INF);

			for (int j = 1; j <= m; j++) {
				if (prevChar != '\0' && j >= 2 && gene.charAt(j - 2) == prevChar) {
					run = Math.min(run, prevE[j - 1]);
				}
				if (dna.charAt(i) != gene.charAt(j - 1)) continue;

				long insertPrefix = (j >= 2 ? pre[j - 2] : 0);
				long f = insertPrefix + Math.min(0L, run);
				curE[j] = f - pre[j - 1];
				ans = Math.min(ans, f + suf[j]);
			}

			prevE = curE;
		}

		System.out.println(ans);
	}
}
```
