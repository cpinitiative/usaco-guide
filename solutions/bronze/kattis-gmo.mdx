## Explanation

We insert characters into the DNA string $S$ so that the gene $G$ appears as a contiguous substring of the resulting string, minimizing the total insertion cost.

Since we never delete or reorder characters, the characters of $S$ that land inside the gene form one **contiguous block** $S[l..r]$. The gene contains these characters in the same order, so this block must be a **subsequence** of $G$.

Now imagine inserting the whole gene, which costs the sum of the insertion costs of its characters. Every character of $S$ that we reuse inside the gene saves its insertion cost, so all we need is the block of $S$ that saves the most cost.

The input gives the four insertion costs in the order $A, C, G, T$.

### Solution

Try every starting position $l$ in $S$. From there, greedily match $S[l], S[l+1], \dots$ against the gene, always taking the earliest position in $G$ holding the needed character. A single pointer into $G$ does this while we walk forward through $S$.

Greedy is enough here: using the earliest available position in $G$ never blocks a later character, so this finds the longest block starting at $l$ that is a subsequence of $G$. Since all costs are non-negative, a longer block saves at least as much cost as any shorter one, so this is the best choice for that $l$.

For each $l$, subtract the saved cost from the cost of inserting the whole gene, and take the minimum.

### Implementation

**Time Complexity:** $\mathcal O(N^2 + NM)$

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(nullptr);

	string dna, gene;
	cin >> dna >> gene;

	// the insertion costs in the order A, C, G, T
	long long cost[4];
	for (int i = 0; i < 4; i++) { cin >> cost[i]; }

	auto id = [](char ch) -> int {
		if (ch == 'A') { return 0; }
		if (ch == 'C') { return 1; }
		if (ch == 'G') { return 2; }
		return 3;  // T
	};

	int n = (int)dna.size();
	int m = (int)gene.size();

	// base = the cost of inserting every character of the gene
	long long base = 0;
	for (char ch : gene) { base += cost[id(ch)]; }

	long long best = base;

	for (int l = 0; l < n; l++) {
		// cur starts as the cost of inserting the whole gene
		long long cur = base;
		int pos = 0;  // the next gene position we may use

		for (int r = l; r < n; r++) {
			// greedily take the earliest matching position in the gene
			while (pos < m && dna[r] != gene[pos]) { pos++; }

			if (pos < m) {
				// this DNA character is reused, so we do not pay for it
				cur -= cost[id(gene[pos])];
				pos++;
			}
		}

		best = min(best, cur);
	}

	cout << best << '\n';

	return 0;
}
```

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class GMO {
	private static int id(char ch) {
		if (ch == 'A') { return 0; }
		if (ch == 'C') { return 1; }
		if (ch == 'G') { return 2; }
		return 3;  // T
	}

	public static void main(String[] args) throws IOException {
		BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
		String dna = br.readLine().trim();
		String gene = br.readLine().trim();

		StringTokenizer st = new StringTokenizer(br.readLine());

		// the insertion costs in the order A, C, G, T
		long[] cost = new long[4];
		for (int i = 0; i < 4; i++) { cost[i] = Long.parseLong(st.nextToken()); }

		int n = dna.length();
		int m = gene.length();

		// base = the cost of inserting every character of the gene
		long base = 0;
		for (int j = 0; j < m; j++) { base += cost[id(gene.charAt(j))]; }

		long best = base;

		for (int l = 0; l < n; l++) {
			// cur starts as the cost of inserting the whole gene
			long cur = base;
			int pos = 0;  // the next gene position we may use

			for (int r = l; r < n; r++) {
				// greedily take the earliest matching position in the gene
				while (pos < m && dna.charAt(r) != gene.charAt(pos)) { pos++; }

				if (pos < m) {
					// this DNA character is reused, so we do not pay for it
					cur -= cost[id(gene.charAt(pos))];
					pos++;
				}
			}

			best = Math.min(best, cur);
		}

		System.out.println(best);
	}
}
```
