## Explanation

Let $x$ denote the number of times Takahashi uses his superpower
before jumping. We know that with every use of the superpower, the
strength of gravity increases by $1$. Therefore, if Takahashi uses
his superpower $x$ times, the gravity becomes $g = x + 1$.

It is also mentioned in the problem that each use of the superpower
takes a time of $B$. So if he uses his superpower $x$ times, the
total time spent on operations will be $x \cdot B$.

After substituting these values, the total time required to reach
the ground becomes:

$$
f(x) = xB + \frac{A}{\sqrt{x + 1}}
$$

Our goal is to find the value $x$ that minimises $f(x)$.

Here, observe that the first term $xB$ is a linear function and
therefore convex. The second term is also convex for $x \geq 0$,
as its second derivative is positive. Since the sum of convex
functions is also convex, $f(x)$ is also convex.

A convex function is also unimodal; hence, $f(x)$ is unimodal
(i.e., it decreases, reaches a minimum, then increases). This
allows us to apply ternary search over the range of possible
values of $x$ to find the minimum time.

```cpp
#include <iostream>
#include <cmath>
#include <iomanip>

int main() {
    long long a, b;
    std::cin >> a >> b;

    auto get_time = [&] (long long mid) -> long double {
        long double res = (long double)mid * b + (a / sqrtl(mid + 1));
        return res;
    };

    long long lo = 0, hi = 1e18;
    while (hi - lo > 3) {
        long long mid1 = lo + (hi - lo) / 3;
        long long mid2 = hi - (hi - lo) / 3;

        if (get_time(mid1) > get_time(mid2)) {
            lo = mid1;
        } else {
            hi = mid2;
        }
    }

    long double min_time = get_time(lo);
    for (long long i = lo + 1; i <= hi; i++) {
        min_time = std::min(min_time, get_time(i));
    }

    std::cout << std::fixed << std::setprecision(8) << min_time << '\n';
}
```
