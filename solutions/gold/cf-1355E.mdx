## Explanation

Firstly, we can agree that $M$ can be $\min(M, A + R)$ since moving a brick
from pillar $a$ to pillar $b$ can never cost more than adding and removing
a brick separately. So whenever one pillar is missing a brick and another
one has some extra bricks, we can always move a brick between them. At the
end, we can either only add bricks or only remove bricks (never both), and
these are just the remainning bricks that could not be paired up with a move.

Now, as we get back to our objective of finding the minimal cost of restoration,
let's say we want to achieve some target height $x$.
Let $P$ be the totl number of missing bricks across all pillars
shorter than $x$, and $Q$ be the total number of extra bricks across
all pillars taller than $x$. We move $\min(P, Q)$ bricks, and the
leftover $|P - Q|$ bricks must be added (if $P \geq Q$) or removed
(if $Q \geq P$). Here, the total cost to make the height of all
pillars $x$ will be:

$$
f(x) = \begin{cases} A(P - Q) + MQ & \text{if } P \geq Q \\ R(Q - P) + MP & \text{if } Q \geq P \end{cases}
$$

and our objective is to find the value $x$ that minimizes $f(x)$.


Let $S = \sum_{i=1}^{N} h_i$, and for a target height $x$ defne

$$
P(x) = \sum_{i=1}^{N} \max(0,\, x - h_i), \qquad
Q(x) = \sum_{i=1}^{N} \max(0,\, h_i - x).
$$

Then $P(x) - Q(x) = \sum_{i=1}^{N} (x - h_i) = Nx - S$, so
$P(x) \geq Q(x)$ exactly when $x \geq \frac{S}{N}$. Therefore,

$$
f(x) =
\begin{cases}
A\,(Nx - S) + M\,Q(x) & \text{if } x \geq \frac{S}{N}, \\
R\,(S - Nx) + M\,P(x) & \text{if } x \leq \frac{S}{N}.
\end{cases}
$$

To show that $f(x)$ is convex, we show that its slope
$\Delta f(x) = f(x+1) - f(x)$ never decreases as $x$ grows.

<Info>

Let $L(x)$ be the number of pillara with height at most $x$, and $G(x)$
be the number of pillars taller than $x$. Then:

$$
\Delta f(x) =
\begin{cases}
AN - M \cdot G(x) & \text{if } x \geq \frac{S}{N}, \\
-RN + M \cdot L(x) & \text{if } x + 1 \leq \frac{S}{N}.
\end{cases}
$$

As $x$ grows, $G(x)$ only decreases and $L(x)$ only increases, so in
both cases the slope never decreases. The slope also does not decrease
at the step where we switch between the two cases. The two expressions
in $f(x)$ differ by $(A + R - M)(Nx - S)$, which is non-negative exactly
when $x \geq \frac{S}{N}$ (since $M \leq A + R$). So $f(x)$ is always the
larger of the two expresions, and a maxmum of convex functions is
convex.

Therefore $\Delta f(x)$ is non-decreasing for every $x$, so $f(x)$ is
convex. You can also verify this visually using
[Desmos](https://www.desmos.com/calculator).

For example, for the sample below, the slope of $f(x)$ only moves
upwards as $x$ increases.

**Sample:** $N = 5$, $A = 3$, $R = 2$, $M = 4$, pillars $= [1, 2, 5, 7, 10]$.

Since $f(x)$ is convex, it is also unimodal, i.e., it decreases,
reaches a minimum, then increases. This allows us to apply ternary
search over the range of possible target heights to find the minimum
cost.


## Implementation

**Time Complexity:** $\mathcal{O}(N \log H)$, where $H$ is the maximum value of $h_i$.

<CPPSection>

```cpp
#include <iostream>
#include <vector>

int main() {
	int n, add, remove, move;
	std::cin >> n >> add >> remove >> move;
	std::vector<int> pillars(n);
	for (int &x : pillars) { std::cin >> x; }

	auto get_cost = [&](int mid) -> long long {
		long long to_add = 0, to_remove = 0;
		for (int p : pillars) {
			if (p < mid) {
				to_add += mid - p;
			} else {
				to_remove += p - mid;
			}
		}

		long long res = 1LL * add * (to_add - std::min(to_add, to_remove)) +
		                1LL * remove * (to_remove - std::min(to_add, to_remove)) +
		                1LL * move * std::min(to_add, to_remove);

		res = std::min(res, 1LL * add * to_add + 1LL * remove * to_remove);

		return res;
	};

	int lo = 0, hi = 1e9;
	while (hi - lo > 3) {
		int mid1 = lo + (hi - lo) / 3;
		int mid2 = hi - (hi - lo) / 3;
		if (get_cost(mid1) > get_cost(mid2)) {
			lo = mid1;
		} else {
			hi = mid2;
		}
	}

	long long min_cost = get_cost(lo);
	for (int i = lo + 1; i <= hi; i++) { min_cost = std::min(min_cost, get_cost(i)); }

	std::cout << min_cost << '\n';
}
```
