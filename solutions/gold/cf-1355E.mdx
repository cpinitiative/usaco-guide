## Explanation

First, we have $M$ equal to $\min(M, A + R)$, since moving a brick
from pillar $a$ to pillar $b$ should never cost more than adding and removing
a brick separately. So whenever one pillar is missing a brick and another
one has extra bricks, we can always move a brick to the shorter pillar.
Hence, we either only add or only remove bricks (never both), and any extra bricks
above our chosen height are moved to pillars that need them.

Now, to find the minimal cost of restoration,
let's say we want to achieve some target height $x$.
Let $P$ be the total number of missing bricks across all pillars
shorter than $x$, and $Q$ be the total number of extra bricks across
all pillars taller than $x$. We move $\min(P, Q)$ bricks, and the
leftover $|P - Q|$ bricks must be added (if $P \geq Q$) or removed
(if $Q \geq P$). Here, the total cost to make the height of all
pillars $x$ will be:

$$
f(x) = \begin{cases} A(P - Q) + MQ & \text{if } P \geq Q \\ R(Q - P) + MP & \text{if } Q \geq P \end{cases}
$$

and our objective is to find the value $x$ that minimizes $f(x)$.


Let $S = \sum_{i=1}^{N} h_i$, and for a target height $x$ define

$$
P(x) = \sum_{i=1}^{N} \max(0,\, x - h_i), \qquad
Q(x) = \sum_{i=1}^{N} \max(0,\, h_i - x).
$$

Then $P(x) - Q(x) = Nx - S$, so $P(x) \geq Q(x)$ exactly when
$x \geq \frac{S}{N}$. We can write the two expressions of 
$f(x)$ as

$$
f_1(x) = A\,(Nx - S) + M\,Q(x), \qquad
f_2(x) = R\,(S - Nx) + M\,P(x),
$$

so that $f(x) = f_1(x)$ for $x \geq \frac{S}{N}$ and $f(x) = f_2(x)$ for
$x \leq \frac{S}{N}$.

<Info title="Why f(x) is convex?">

Both $P(x)$ and $Q(x)$ are sums of terms like $\max(0, x - h_i)$ terms, which are
convex, and adding a linear term keeps a function convex. So $f_1$ and
$f_2$ are both convex.

Now, using $M \leq A + R$, we get

$$
f_1(x) - f_2(x) = (A + R - M)(P(x) - Q(x)) = (A + R - M)(Nx - S),
$$

which is non-negative exactly when $x \geq \frac{S}{N}$. This means
$f(x) = \max(f_1(x), f_2(x))$ everywhere, and the maximum of two convex
functions is convex. So $f(x)$ is convex.

</Info>

Since $f(x)$ is convex, it is also unimodal, i.e., it decreases, reaches
a minimum, then increases. This allows us to apply ternary search over
the range of possible target heights to find the minimum cost.

## Implementation

**Time Complexity:** $\mathcal{O}(N \log H)$, where $H$ is the maximum value of $h_i$.

```cpp
#include <iostream>
#include <vector>

int main() {
	int n, add, remove, move;
	std::cin >> n >> add >> remove >> move;
	std::vector<int> pillars(n);
	for (int &x : pillars) { std::cin >> x; }

	auto get_cost = [&](int mid) -> long long {
		long long to_add = 0, to_remove = 0;
		for (int p : pillars) {
			if (p < mid) {
				to_add += mid - p;
			} else {
				to_remove += p - mid;
			}
		}

		long long res = 1LL * add * (to_add - std::min(to_add, to_remove)) +
		                1LL * remove * (to_remove - std::min(to_add, to_remove)) +
		                1LL * move * std::min(to_add, to_remove);

		res = std::min(res, 1LL * add * to_add + 1LL * remove * to_remove);

		return res;
	};

	int lo = 0, hi = 1e9;
	while (hi - lo > 3) {
		int mid1 = lo + (hi - lo) / 3;
		int mid2 = hi - (hi - lo) / 3;
		if (get_cost(mid1) > get_cost(mid2)) {
			lo = mid1;
		} else {
			hi = mid2;
		}
	}

	long long min_cost = get_cost(lo);
	for (int i = lo + 1; i <= hi; i++) { min_cost = std::min(min_cost, get_cost(i)); }

	std::cout << min_cost << '\n';
}
```
