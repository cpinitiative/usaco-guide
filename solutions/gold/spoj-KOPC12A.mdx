## Explanation

Let's define a function $f(x)$ as the total cost required to make
all buildings have height $x$. For the $i^{th}$ building to obtain
height $x$, the cost contributed by it will be:

$$
g_i(x) = |x - h_i| \cdot c_i
$$

Therefore, the total reconstruction cost is:
$$
f(x) = \sum_{i=1}^{n} g_i(x) = \sum_{i=1}^{n} |x - h_i| \cdot c_i
$$

Our final goal is to find the value $x$ which minimises $f(x)$.

We know that $g_i(x)$ is a convex function of $x$, and for a
fact we also know that the sum of convex functions is also convex,
which means $f(x)$ will eventually be convex.

This means $f(x)$ is unimodal (i.e., the function strictly decreases
first, then reaches a minimum, then strictly increases). This
allows us to apply ternary search over the range of possible
heights to find the minimum cost.


## Implementation

**Time Complexity:** $\mathcal{O}(N \log (max\_height))$

void solve() {
	int n;
	std::cin >> n;
	std::vector<int> heights(n), costs(n);

	for (int &x : heights) { std::cin >> x; }

	for (int &x : costs) { std::cin >> x; }

	auto is_possible = [&](int mid) {
		long long res = 0;
		for (int i = 0; i < n; i++) { res += std::abs(mid - heights[i]) * costs[i]; }
		return res;
	};

	int lo = 0, hi = 10000;
	while (hi - lo > 3) {
		int mid1 = lo + (hi - lo) / 3;
		int mid2 = hi - (hi - lo) / 3;
		if (is_possible(mid1) > is_possible(mid2)) {
			lo = mid1;
		} else {
			hi = mid2;
		}
	}

	long long min_cost = is_possible(lo);
	for (int i = lo + 1; i <= hi; i++) {
		min_cost = std::min(min_cost, is_possible(i));
	}

	std::cout << min_cost << '\n';
}

int main() {

}
