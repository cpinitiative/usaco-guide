## Explanation

In a standard Bounded Knapsack problem (where the $i$-th item type has $K_i$ copies), a naive approach is to treat every copy as a separate item and run standard 0/1 Knapsack. However, 0/1 Knapsack runs in $\mathcal{O}(\text{items} \times S)$ time. With $S \le 2000$ and a 1-second time limit (roughly $10^8$ operations), we can only afford to process around $5 \times 10^4$ individual items. Here, $N \le 10^5$ and $K_i \le 10^9$, which can produce up to $10^{14}$ items which is far too many to pass without getting TLE.

Fortunately, the constraint $S \le 2000$ (the maximum basket weight is very small) allows us to drastically reduce the number of items we need to consider.

### Observation 1: Cap the items per weight
Consider all items that weigh $w$ kg. Even if there are a billion copies available, your basket can only hold $S$ kg in total. Therefore, you can **never** take more than $\lfloor S / w \rfloor$ items of weight $w$.

### Observation 2: Be greedy within the same weight
Among items that have the exact same weight $w$, it is always optimal to pick the ones with the highest value first. 

Because of Observations 1 and 2, we can group all item types by their weight $w$, sort each group by value in descending order, and keep only the **top $\lfloor S / w \rfloor$ individual items** for each weight. Every other item can be safely discarded.

### Observation 3: Counting the remaining items
Before running 0/1 Knapsack on our filtered items, we need to verify that the total number of remaining items is small enough to avoid TLE. To find the worst-case number of items kept, we sum the maximum possible items across every weight from $1$ to $S$:

$$\sum_{w=1}^{S} \left\lfloor \frac{S}{w} \right\rfloor \le S \left(1 + \frac{1}{2} + \frac{1}{3} + \dots + \frac{1}{S}\right)$$

The expression $1 + \frac{1}{2} + \frac{1}{3} + \dots + \frac{1}{S}$ is the **Harmonic Series**, which is bounded above by $1 + \ln(S)$ (so it grows at a rate of $\mathcal{O}(\log S)$).
- For $S = 2000$, $1 + \ln(2000) \approx 8.6$.
- Thus, the total number of items kept is at most $2000 \times 8.6 \approx 17,200$.

### Putting It Together
We have reduced up to $10^{14}$ items down to at most $\approx 17,200$ usable items. We can now solve the problem in three clean, separate phases:
1. **Group:** Bucket all item types by their weight $w$.
2. **Filter:** For each weight $w$, sort by value descending and extract at most $\lfloor S / w \rfloor$ individual items into a single list.
3. **DP:** Run standard 1D 0/1 Knapsack DP on the filtered list (iterating weights backwards from $S$ down to $w$ so each item is used at most once).

**Time Complexity:** $\mathcal{O}(N \log N + S^2 \log S)$
* Sorting the items takes at most $\mathcal{O}(N \log N)$.
* Running 0/1 Knapsack on $\mathcal{O}(S \log S)$ items with capacity $S$ takes $\mathcal{O}(S^2 \log S)$ time ($\approx 17,200 \times 2000 \approx 3.4 \times 10^7$ operations, which comfortably passes within 1 second).

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

using namespace std;

int main() {
	int max_weight, num_types;
	cin >> max_weight >> num_types;

	// Phase 1: Group item types by their weight
	// items_by_weight[w] stores pairs of {value, copies} for items weighing w
	vector<vector<pair<int, int>>> items_by_weight(max_weight + 1);
	for (int i = 0; i < num_types; i++) {
		int value, weight, copies;
		cin >> value >> weight >> copies;
		if (weight <= max_weight && copies > 0) {
			items_by_weight[weight].push_back({value, copies});
		}
	}

	// Phase 2: For each weight w, keep only the top floor(max_weight / w) most valuable items
	vector<pair<int, int>> filtered_items;  // {weight, value}
	for (int weight = 1; weight <= max_weight; weight++) {
		if (items_by_weight[weight].empty()) continue;

		// Sort by value in descending order
		sort(items_by_weight[weight].begin(), items_by_weight[weight].end(),
		     greater<pair<int, int>>());

		int max_usable = max_weight / weight;
		int taken = 0;

		for (auto [value, copies] : items_by_weight[weight]) {
			int take_now = min(copies, max_usable - taken);
			for (int i = 0; i < take_now; i++) {
				filtered_items.push_back({weight, value});
			}
			taken += take_now;
			if (taken == max_usable) break;
		}
	}

	// Phase 3: Standard 1D 0/1 Knapsack DP on the filtered items
	// dp[w] = maximum value achievable with total weight at most w
	vector<long long> dp(max_weight + 1, 0);
	for (auto [weight, value] : filtered_items) {
		// Iterate backwards so each item is used at most once
		for (int curr_weight = max_weight; curr_weight >= weight; curr_weight--) {
			dp[curr_weight] = max(dp[curr_weight], dp[curr_weight - weight] + value);
		}
	}

	cout << dp[max_weight] << "\n";
}
```

```java
import java.io.*;
import java.util.*;

public class knapsack {
	public static void main(String[] args) throws IOException {
		BufferedReader read = new BufferedReader(new InputStreamReader(System.in));
		StringTokenizer initial = new StringTokenizer(read.readLine());
		int maxWeight = Integer.parseInt(initial.nextToken());
		int numTypes = Integer.parseInt(initial.nextToken());

		// Phase 1: Group item types by their weight
		// itemsByWeight[w] stores pairs of {value, copies} for items weighing w
		@SuppressWarnings("unchecked")
		ArrayList<int[]>[] itemsByWeight = new ArrayList[maxWeight + 1];
		for (int weight = 1; weight <= maxWeight; weight++) {
			itemsByWeight[weight] = new ArrayList<>();
		}

		for (int i = 0; i < numTypes; i++) {
			StringTokenizer item = new StringTokenizer(read.readLine());
			int value = Integer.parseInt(item.nextToken());
			int weight = Integer.parseInt(item.nextToken());
			int copies = Integer.parseInt(item.nextToken());
			if (weight <= maxWeight && copies > 0) {
				itemsByWeight[weight].add(new int[] {value, copies});
			}
		}

		// Phase 2: For each weight w, keep only the top floor(maxWeight / w) most valuable items
		ArrayList<int[]> filteredItems = new ArrayList<>();  // {weight, value}
		for (int weight = 1; weight <= maxWeight; weight++) {
			if (itemsByWeight[weight].isEmpty()) continue;

			// Sort by value in descending order
			itemsByWeight[weight].sort((a, b) -> Integer.compare(b[0], a[0]));

			int maxUsable = maxWeight / weight;
			int taken = 0;

			for (int[] item : itemsByWeight[weight]) {
				int value = item[0];
				int copies = item[1];
				int takeNow = Math.min(copies, maxUsable - taken);
				for (int i = 0; i < takeNow; i++) {
					filteredItems.add(new int[] {weight, value});
				}
				taken += takeNow;
				if (taken == maxUsable) break;
			}
		}

		// Phase 3: Standard 1D 0/1 Knapsack DP on the filtered items
		// dp[w] = maximum value achievable with total weight at most w
		long[] dp = new long[maxWeight + 1];
		for (int[] item : filteredItems) {
			int weight = item[0];
			int value = item[1];
			// Iterate backwards so each item is used at most once
			for (int currWeight = maxWeight; currWeight >= weight; currWeight--) {
				dp[currWeight] = Math.max(dp[currWeight], dp[currWeight - weight] + value);
			}
		}

		System.out.println(dp[maxWeight]);
	}
}
```
