## Explanation

If we construct a graph where edges have weights equal to the time they are added, the problem boils down to efficiently finding the path with the minimum maximum edge for each query.

Let's consider a single query between nodes $u, v$. One way of approaching this is to sort the edge weights from smallest to largest, and then add edges one by one until $u$ and $v$ are connected. If we use a [disjoint set union](/gold/dsu), the time complexity for each query is $\mathcal{O}(m \cdot \alpha(n))$, which is too slow.

However, this hints at a faster solution. Note that our slow approach bears many similarities with [Kruskal's MST algorithm](/gold/mst/#kruskals), which implies that the path between $u$ and $v$ on any minimum spanning tree will minimize the maximum edge weight. For a more formal proof, see [here](https://www.geeksforgeeks.org/minimum-bottleneck-spanning-treembst/).

All that is left to do is to efficiently query for the maximum edge on a tree path. One way to do this is with [binary jumping](/plat/binary-jump).

## Implementation

**Time Complexity:** $\mathcal{O}(m \cdot \alpha(n) + n\log n)$

```cpp
#include <bits/stdc++.h>

using namespace std;

const int MAXN = 2e5 + 1;
const int LOGN = 18;  // log of MAXN base 2

// Simple DSU class with Small to Large merging
template <size_t N> struct UnionFind {
	int par[N], sze[N], max_size;

	UnionFind(int n = N) { init(n); }

	void init(int n = N) {
		iota(par, par + n, 0);
		fill(sze, sze + n, 1);
		max_size = 1;
	}

	int find(int a) {
		if (a == par[a]) return a;
		return par[a] = find(par[a]);
	}

	bool merge(int a, int b) {
		a = find(a), b = find(b);
		if (a == b) return 0;

		if (sze[a] > sze[b]) {
			par[b] = a;
			sze[a] += sze[b];
			max_size = max(max_size, sze[a]);
		} else {
			par[a] = b;
			sze[b] += sze[a];
			max_size = max(max_size, sze[b]);
		}
		return 1;
	}

	int size(int a) { return sze[find(a)]; }
};

int N, M, Q;
vector<pair<int, int>> G[MAXN];
UnionFind<MAXN> dsu;

namespace LCA {
int dep[MAXN], par[MAXN][LOGN], val[MAXN][LOGN];

void dfs_init(int u, int p, int d) {
	dep[u] = d;
	par[u][0] = p;
	for (auto [v, w] : G[u])
		if (p != v) {
			val[v][0] = w;
			dfs_init(v, u, d + 1);
		}
}

void init() {
	memset(dep, -1, sizeof(dep));
	memset(par, 0, sizeof(par));
	memset(val, 0, sizeof(val));

	for (int i = 1; i <= N; i++)
		if (dep[i] == -1) dfs_init(i, i, 0);
	for (int k = 1; k < LOGN; k++)
		for (int i = 1; i <= N; i++) {
			par[i][k] = par[par[i][k - 1]][k - 1];
			val[i][k] = max(val[i][k - 1], val[par[i][k - 1]][k - 1]);
		}
}

int query(int a, int b) {
	if (dep[a] > dep[b]) swap(a, b);

	// gets a and b to the same depth
	int ans = 0;
	for (int d = LOGN - 1; d >= 0; d--)
		if (dep[b] - (1 << d) >= dep[a]) {
			ans = max(ans, val[b][d]);
			b = par[b][d];
		}

	if (a == b) return ans;

	for (int d = LOGN - 1; d >= 0; d--)
		if (par[a][d] != par[b][d]) {
			ans = max(ans, val[a][d]);
			a = par[a][d];
			ans = max(ans, val[b][d]);
			b = par[b][d];
		}
	if (par[a][0] != par[b][0]) return -1;
	ans = max(ans, val[a][0]);
	ans = max(ans, val[b][0]);

	return ans;
}
}  // namespace LCA

int main() {
	ios::sync_with_stdio(false);
	cin.tie(NULL);

	dsu.init();

	cin >> N >> M >> Q;
	for (int i = 1; i <= M; i++) {
		int u, v;
		cin >> u >> v;
		if (dsu.merge(u, v)) {
			G[u].emplace_back(v, i);
			G[v].emplace_back(u, i);
		}
	}

	LCA::init();

	while (Q--) {
		int u, v;
		cin >> u >> v;
		cout << LCA::query(u, v) << '\n';
	}
}
```

## Alternative Solution

The solution above uses [binary jumping](/plat/binary-jump), which is a Platinum topic. Here is a simpler approach that only needs a disjoint set union.

We add the roads to a DSU in order, but without path compression, so the parent pointers keep the history of the merges. Whenever a root $v$ is attached under another root, we record $\texttt{joined\_on}[v]$, the day this happened (it stays $\infty$ while $v$ is a root). With union by size, a vertex only gets deeper when its component at least doubles in size, so every tree has height at most $\log_2 n$.

We label the link from $v$ to its parent with $\texttt{joined\_on}[v]$. The parent $p$ of $v$ was still a root when $v$ was attached, so $p$ is attached later (or never). This means the labels strictly increase as we go up from any vertex to the root of its tree. Two cities are connected on day $d$ exactly when they can both climb to the same vertex using only links with label at most $d$. So the answer to a query is the largest label on the path between the two cities in the forest, or $-1$ if they are in different trees.

To find it, we keep two pointers at $a$ and $b$ and always move up the one whose link has the smaller label. This merges two increasing sequences of labels, so the last label we pass is the largest. The climb stops exactly at the lowest common ancestor: if one pointer reaches it first, the other pointer is still below it, and its label is smaller than the label of the lowest common ancestor's own link, so the other pointer is the one that moves. If both pointers stop at different roots, the answer is $-1$, and if $a=b$ the answer is $0$.

For example, in the sample, the roads on days $1$, $2$, and $4$ attach vertices $2$, $3$, and $5$ under vertex $1$, with labels $1$, $2$, and $4$ (the road on day $3$ joins vertices that are already connected, so it changes nothing). For the query $(3,5)$, we climb from $3$ (label $2$) and from $5$ (label $4$) up to vertex $1$, so the answer is $4$.

**Time Complexity:** $\mathcal{O}((m+q)\log n)$

```cpp
#include <bits/stdc++.h>
using namespace std;

const int NEVER = INT_MAX;

int main() {
	ios::sync_with_stdio(false);
	cin.tie(nullptr);

	int n, m, q;
	cin >> n >> m >> q;

	// parent[v]:    parent in the union-find forest (v itself if v is a root)
	// joined_on[v]: day v stopped being a root (NEVER if it is still a root)
	vector<int> parent(n + 1), comp_size(n + 1, 1), joined_on(n + 1, NEVER);
	iota(parent.begin(), parent.end(), 0);

	// No path compression, because it would rewrite the merge history.
	// Union by size alone keeps every tree's height at most log2(n).
	auto find_root = [&](int v) {
		while (parent[v] != v) v = parent[v];
		return v;
	};

	for (int day = 1; day <= m; day++) {
		int a, b;
		cin >> a >> b;
		a = find_root(a);
		b = find_root(b);
		if (a == b) continue;
		if (comp_size[a] < comp_size[b]) swap(a, b);
		parent[b] = a;
		comp_size[a] += comp_size[b];
		joined_on[b] = day;
	}

	while (q--) {
		int a, b;
		cin >> a >> b;

		// Always move up the vertex that was attached earlier. The last
		// label we pass before the two pointers meet is the answer.
		int answer = 0;
		while (a != b) {
			if (joined_on[a] > joined_on[b]) swap(a, b);
			if (joined_on[a] == NEVER) {  // neither can climb, so never connected
				answer = -1;
				break;
			}
			answer = joined_on[a];
			a = parent[a];
		}
		cout << answer << '\n';
	}
}
```
