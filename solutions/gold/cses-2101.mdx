# Solution 1 (Binary Jumping)

## Explanation

If we construct a graph where edges have weights equal to the time they are added, the problem boils down to efficiently finding the path with the minimum maximum edge for each query.

Let's consider a single query between nodes $u, v$. One way of approaching this is to sort the edge weights from smallest to largest, and then add edges one by one until $u$ and $v$ are connected. If we use a [disjoint set union](/gold/dsu), the time complexity for each query is $\mathcal{O}(m \cdot \alpha(n))$, which is too slow.

However, this hints at a faster solution. Note that our slow approach bears many similarities with [Kruskal's MST algorithm](/gold/mst/#kruskals), which implies that the path between $u$ and $v$ on any minimum spanning tree will minimize the maximum edge weight. For a more formal proof, see [here](https://www.geeksforgeeks.org/minimum-bottleneck-spanning-treembst/).

All that is left to do is to efficiently query for the maximum edge on a tree path. One way to do this is with [binary jumping](/plat/binary-jump).

## Implementation

**Time Complexity:** $\mathcal{O}(m \cdot \alpha(n) + n\log n)$

```cpp
#include <bits/stdc++.h>

using namespace std;

const int MAXN = 2e5 + 1;
const int LOGN = 18;  // log of MAXN base 2

// Simple DSU class with Small to Large merging
template <size_t N> struct UnionFind {
	int par[N], sze[N], max_size;

	UnionFind(int n = N) { init(n); }

	void init(int n = N) {
		iota(par, par + n, 0);
		fill(sze, sze + n, 1);
		max_size = 1;
	}

	int find(int a) {
		if (a == par[a]) return a;
		return par[a] = find(par[a]);
	}

	bool merge(int a, int b) {
		a = find(a), b = find(b);
		if (a == b) return 0;

		if (sze[a] > sze[b]) {
			par[b] = a;
			sze[a] += sze[b];
			max_size = max(max_size, sze[a]);
		} else {
			par[a] = b;
			sze[b] += sze[a];
			max_size = max(max_size, sze[b]);
		}
		return 1;
	}

	int size(int a) { return sze[find(a)]; }
};

int N, M, Q;
vector<pair<int, int>> G[MAXN];
UnionFind<MAXN> dsu;

namespace LCA {
int dep[MAXN], par[MAXN][LOGN], val[MAXN][LOGN];

void dfs_init(int u, int p, int d) {
	dep[u] = d;
	par[u][0] = p;
	for (auto [v, w] : G[u])
		if (p != v) {
			val[v][0] = w;
			dfs_init(v, u, d + 1);
		}
}

void init() {
	memset(dep, -1, sizeof(dep));
	memset(par, 0, sizeof(par));
	memset(val, 0, sizeof(val));

	for (int i = 1; i <= N; i++)
		if (dep[i] == -1) dfs_init(i, i, 0);
	for (int k = 1; k < LOGN; k++)
		for (int i = 1; i <= N; i++) {
			par[i][k] = par[par[i][k - 1]][k - 1];
			val[i][k] = max(val[i][k - 1], val[par[i][k - 1]][k - 1]);
		}
}

int query(int a, int b) {
	if (dep[a] > dep[b]) swap(a, b);

	// gets a and b to the same depth
	int ans = 0;
	for (int d = LOGN - 1; d >= 0; d--)
		if (dep[b] - (1 << d) >= dep[a]) {
			ans = max(ans, val[b][d]);
			b = par[b][d];
		}

	if (a == b) return ans;

	for (int d = LOGN - 1; d >= 0; d--)
		if (par[a][d] != par[b][d]) {
			ans = max(ans, val[a][d]);
			a = par[a][d];
			ans = max(ans, val[b][d]);
			b = par[b][d];
		}
	if (par[a][0] != par[b][0]) return -1;
	ans = max(ans, val[a][0]);
	ans = max(ans, val[b][0]);

	return ans;
}
}  // namespace LCA

int main() {
	ios::sync_with_stdio(false);
	cin.tie(NULL);

	dsu.init();

	cin >> N >> M >> Q;
	for (int i = 1; i <= M; i++) {
		int u, v;
		cin >> u >> v;
		if (dsu.merge(u, v)) {
			G[u].emplace_back(v, i);
			G[v].emplace_back(u, i);
		}
	}

	LCA::init();

	while (Q--) {
		int u, v;
		cin >> u >> v;
		cout << LCA::query(u, v) << '\n';
	}
}
```

# Solution 2 (DSU)

## Explanation

The solution above uses [binary jumping](/plat/binary-jump), which is a Platinum topic. Here is a simpler approach that only needs a [disjoint set union](/gold/dsu).

We add the roads to a DSU in order of day, using union by size but no path compression. This way, the parent pointers form a forest that keeps the full history of the merges, and every tree has height at most $\log_2 n$, since a vertex only gets deeper when the size of its component at least doubles.

Cities $a$ and $b$ first become connected on the day of the road that unites their components, so that day is the answer. Whenever a root is attached under another root, we store the current day on the attached root. The road that unites $a$ and $b$ stores its day on the path between them, and every other day on this path comes from an earlier merge, so the answer is the largest day stored on the path. If $a$ and $b$ are in different trees, the answer is $-1$.

To find it, we walk up from $a$ and $b$ until they meet, similar to finding their lowest common ancestor. A vertex is always attached before its parent is, so the stored days increase as we go up. This means we can always move up the vertex with the smaller stored day, and the last day we pass before the two meet is the answer.

For example, in the sample, the roads on days $1$, $2$, and $4$ attach vertices $2$, $3$, and $5$ under vertex $1$ (the road on day $3$ connects cities that are already connected). For the query $(3, 5)$, we move up from $3$ (day $2$) and then from $5$ (day $4$), and both reach vertex $1$, so the answer is $4$.

## Implementation

**Time Complexity:** $\mathcal{O}((m+q)\log n)$

```cpp
#include <bits/stdc++.h>
using namespace std;

const int NEVER = INT_MAX;

// DSU without path compression, so the forest keeps the merge history.
// Union by size alone keeps every tree's height at most log2(n).
struct DSU {
	// parent[v]:    parent in the forest (v itself if v is a root)
	// joined_on[v]: day v stopped being a root (NEVER if it is still a root)
	vector<int> parent, comp_size, joined_on;

	DSU(int n) : parent(n + 1), comp_size(n + 1, 1), joined_on(n + 1, NEVER) {
		iota(parent.begin(), parent.end(), 0);
	}

	int find(int v) {
		while (parent[v] != v) v = parent[v];
		return v;
	}

	void unite(int a, int b, int day) {
		a = find(a);
		b = find(b);
		if (a == b) return;
		if (comp_size[a] < comp_size[b]) swap(a, b);
		parent[b] = a;
		comp_size[a] += comp_size[b];
		joined_on[b] = day;
	}

	// Returns the first day a and b are connected, or -1 if never.
	int query(int a, int b) {
		int answer = 0;
		while (a != b) {
			// Always move up the vertex that was attached earlier.
			if (joined_on[a] > joined_on[b]) swap(a, b);
			if (joined_on[a] == NEVER) return -1;  // both are roots
			answer = joined_on[a];
			a = parent[a];
		}
		return answer;
	}
};

int main() {
	ios::sync_with_stdio(false);
	cin.tie(nullptr);

	int n, m, q;
	cin >> n >> m >> q;
	DSU dsu(n);
	for (int day = 1; day <= m; day++) {
		int a, b;
		cin >> a >> b;
		dsu.unite(a, b, day);
	}
	while (q--) {
		int a, b;
		cin >> a >> b;
		cout << dsu.query(a, b) << '\n';
	}
}
```
