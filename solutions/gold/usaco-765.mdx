## Explanation

For the sake of convenience, let pies $0 \dots N-1$ be Bessie's and $N \dots 2N-1$ be Elsie's. Let $\texttt{B}[i]$ be how tasty Bessie finds pie $i$ and $\texttt{E}[i]$ be how tasty Elsie finds it.

If Elsie receives a pie $p$, she must give a pie $q$ of her own with

$$\texttt{E}[p] \le \texttt{E}[q] \le \texttt{E}[p] + D$$

if it exists. If Bessie receives $q$, she must give $r$ with $\texttt{B}[q] \le \texttt{B}[r] \le \texttt{B}[q] + D$. If a cow receives a pie she values at $0$, the exchange ends.

We want the shortest exchange starting from each Bessie pie.

If we try to go forward, one pie can go to many others and building all edges is $O(N^2)$. Instead, frame it backwards: if we already know the answer for $\texttt{cur}$, which pies could have come right before $\texttt{cur}$?

### Reverse BFS

A pie that ends the exchange in $1$ step is a source. So we start BFS with all pies where $\texttt{E}[i]=0$ (Bessie pies) and $\texttt{B}[i]=0$ (Elsie pies) with $\texttt{dist}=1$. That's multi-source BFS.

Rather than following edges forward, we go in reverse. When we process $u$:

- If $u$ is a Bessie pie, its predecessors are Elsie pies $v$ with $\texttt{B}[v] \le \texttt{B}[u] \le \texttt{B}[v]+D$, or rearranged,
$$\texttt{B}[u]-D \le \texttt{B}[v] \le \texttt{B}[u]$$

- If $u$ is an Elsie pie, its predecessors are Bessie pies $v$ with
$$\texttt{E}[u]-D \le \texttt{E}[v] \le \texttt{E}[u]$$

So each step is: find all undiscovered pies whose value lies in an interval, give them $\texttt{dist}[u]+1$.

Because BFS processes vertices in nondecreasing distance, the first time we discover a pie its distance is already minimal. Following parent pointers gives a valid happy exchange, so we never need to track used pies explicitly.

### Finding predecessors efficiently

Naively, we would scan all unvisited pies each time:

```
for each unvisited pie v:
  if value in [low, high]: push v
```

That's $O(N^2)$.

Notice the condition is a contiguous interval. Keep two ordered sets:

- $\texttt{bessiePies}$: unvisited Bessie pies ordered by $\texttt{E}$
- $\texttt{elsiePies}$: unvisited Elsie pies ordered by $\texttt{B}$

When processing $u$, we `lower_bound` the start of the interval in the opposite set and walk forward while the value $\le high$. Each pie we meet is discovered and erased immediately.

Each pie is inserted once and erased once, so total work is $\mathcal{O}(N \log N)$. Any Bessie pie never reached gets $-1$.

## Implementation

**Time Complexity:** $\mathcal{O}(N \log N)$

**Space Complexity:** $\mathcal{O}(N)$

```cpp
#include <bits/stdc++.h>
using namespace std;

using ll = long long;

int main() {
	freopen("piepie.in", "r", stdin);
	freopen("piepie.out", "w", stdout);
	ios::sync_with_stdio(false);
	cin.tie(nullptr);

	int N;
	ll D;
	cin >> N >> D;

	vector<ll> bessieValue(2 * N), elsieValue(2 * N);
	for (int i = 0; i < 2 * N; i++) { cin >> bessieValue[i] >> elsieValue[i]; }

	// Bessie's unreached pies, ordered by how tasty Elsie finds them.
	set<pair<ll, int>> bessiePies;
	// Elsie's unreached pies, ordered by how tasty Bessie finds them.
	set<pair<ll, int>> elsiePies;

	vector<int> dist(2 * N, -1);
	queue<int> bfs;

	// A pie valued 0 by its recipient ends the exchange immediately.
	for (int i = 0; i < N; i++) {
		if (elsieValue[i] == 0) {
			dist[i] = 1;
			bfs.push(i);
		} else {
			bessiePies.insert({elsieValue[i], i});
		}
	}
	for (int i = N; i < 2 * N; i++) {
		if (bessieValue[i] == 0) {
			dist[i] = 1;
			bfs.push(i);
		} else {
			elsiePies.insert({bessieValue[i], i});
		}
	}

	const int MIN_INDEX = numeric_limits<int>::min();

	while (!bfs.empty()) {
		int current = bfs.front();
		bfs.pop();

		if (current < N) {
			// Current is Bessie's pie. Predecessors are Elsie pies with
			// B in [B[current]-D, B[current]].
			ll low = bessieValue[current] - D;
			ll high = bessieValue[current];
			auto it = elsiePies.lower_bound({low, MIN_INDEX});
			while (it != elsiePies.end() && it->first <= high) {
				int previous = it->second;
				dist[previous] = dist[current] + 1;
				bfs.push(previous);
				it = elsiePies.erase(it);
			}
		} else {
			// Current is Elsie's pie. Predecessors are Bessie pies with
			// E in [E[current]-D, E[current]].
			ll low = elsieValue[current] - D;
			ll high = elsieValue[current];
			auto it = bessiePies.lower_bound({low, MIN_INDEX});
			while (it != bessiePies.end() && it->first <= high) {
				int previous = it->second;
				dist[previous] = dist[current] + 1;
				bfs.push(previous);
				it = bessiePies.erase(it);
			}
		}
	}

	for (int i = 0; i < N; i++) { cout << dist[i] << '\n'; }
}
```
