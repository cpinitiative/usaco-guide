### Explanation

As we've discussed before, matroids provide a perspective to understand Kruskal's MST algorithm. It turns out that the theory of matroids can also be used to find second-best spanning trees. Formally, we're given a weighted undirected graph, and we want to find the best suboptimal (meaning non-minimum weight) spanning tree, or decide that all spanning trees are optimal (or that there aren't any at all).

One natural way to generate low-weight suboptimal spanning trees is to start off with an MST, then consider adding edges that _aren't_ in the MST. For each such edge $(u,v)$, if we add it to our MST, we create a cycle. To restore our tree, we remove the __highest__ weight edge along the path between $u$ and $v$ (in our original tree) subject to the constraint that the weight of the resulting spanning tree should be greater than the weight of our original MST. This constraint just means that sometimes we'll have to remove the _second_ highest weight edge along the path between $u$ and $v$.

The optimality of this algorithm follows from a general fact about weighted matroids:

> **Second-Best Basis Theorem:** Suppose we have a matroid that admits a sub-optimal weight basis. Let $B$ be a min weight basis. Then, there exists a second-min weight basis $B'$ such that $B'=B-x+y$ for some $x\in B$ and $y\notin B$.

The algorithm we've described iterates over $y\notin B$ (the edge $(u,v)$ we add), then determines the best possible $x\in B$ to remove in order to achieve the lowest possible suboptimal weight.

<Spoiler title="Proof of the above fact">

As a reminder, we will prove the following statement:
> **Theorem:** Suppose there exists a sub-optimal weight basis, and let $B$ be a min weight basis. Then, there exists a second-min weight basis $B'$ such that $B'=B-x+y$ for some $x\in B$ and $y\notin B$.

To prove this, we will use the following result (introduced in the *Matroid Theory* PDF linked in the Matroid module resources):

> **Strong Basis Exchange Lemma:** For any two bases $B_1, B_2$ of a matroid and any element $x \in B_1 \setminus B_2$, there exists an element $y \in B_2 \setminus B_1$ such that both $B_1 - x + y$ and $B_2 - y + x$ are bases.

Let $B'$ be a second-min weight basis. We will inductively modify $B'$ until we find a second-min weight basis that's one element exchange away from $B$. To do this, order the elements of the ground set in non-decreasing weight: $\{e_1,e_2,\dots,e_n\}$. Note that $B\neq B'$ but they have the same cardinality, so there must exist some smallest $i\in[1,n]$ such that $e_i$ belongs to exactly one of $B$ and $B'$.

First, consider the case where $e_i\in B'\setminus B$. Let $e_j\in B\setminus B'$ be as in the strong basis exchange lemma when using $e_i\in B'\setminus B$. Observe that $i<j$ because by minimality of $i$, both $B$ and $B'$ agree before the $i$th element. So, $w(e_i)\leq w(e_j)$. On the other hand, by construction we have that $B-e_j+e_i$ is a basis. So:
$$
\begin{equation*}
\begin{split}
    &w(B)\leq w(B-e_j+e_i)\text{ since $B$ is a min-weight basis}\\
    \implies&w(B)\leq w(B)-w(e_j)+w(e_i)\\
    \implies&0\leq-w(e_j)+w(e_i)\\
    \implies&w(e_j)\leq w(e_i)
\end{split}
\end{equation*}
$$
Therefore, $w(e_i)=w(e_j)$. Hence, we may replace $B'$ with $B'-e_i+e_j$ without modifying its weight, and this is also a basis by construction. This new basis agrees with $B$ up to the $i$th index, so we continue the algorithm.

The other case is when $e_i\in B\setminus B'$. Let $e_j\in B'\setminus B$ be as in the strong basis exchange lemma when using $e_i\in B\setminus B'$. Exactly as before, we have $w(e_i)\leq w(e_j)$. Furthermore, suppose that $w(e_i)\neq w(e_j)$ because if they're equal, we can replace $B'$ with $B'-e_j+e_i$ just as before and continue the algorithm.

Observe:
$$
\begin{equation*}
\begin{split}
    w(B'-e_j+e_i)&=w(B')+(w(e_i)-w(e_j))\\
    &<w(B')\text{ since $w(e_i)<w(e_j)$ as they're not equal}
\end{split}
\end{equation*}
$$
But, $B'$ has the second-lowest weight. Therefore, as we decrease it by modifying $B'\to B'-e_j+e_i$ (which is also a basis), it must be the case that $w(B'-e_j+e_i)=w(B)$ because $B$ is a min weight basis. Hence:
$$
\begin{equation*}
\begin{split}
    &w(B'-e_j+e_i)=w(B)\text{ from before}\\
    \implies&w(B')-w(e_j)+w(e_i)=w(B)\\
    \implies&w(B')=w(B)+w(e_j)-w(e_i)\\
    \implies&w(B')=w(B-e_i+e_j)
\end{split}
\end{equation*}
$$
Therefore, $B-e_i+e_j$ is a second-min weight basis which is what we wanted to construct. So, we terminate the algorithm when this happens.

To conclude the argument, suppose for contradiction that the algorithm iterates over all the elements of the ground set and doesn't find the above case. In that event, we would've modified $B'$ to exactly equal $B$. But, that's impossible since each modification doesn't change the weight, and we assume that $w(B)<w(B')$.
</Spoiler>

### Implementation
Our implementation starts by computing an MST of the given graph using Kruskal's algorithm. Then, we use binary lifting: for each node $x$ and each $k\in[0,\lceil \log_2 n \rceil)$, we compute the maximum weight out of all edges going up $2^k$ nodes, the _second_ maximum weight (i.e. the greatest that's strictly less), and also the node that's $2^k$ up. If the max or second max don't exist, we use $-\infty$. This is because ideally, we'd like to remove the edge with the maximum weight. However if that results in a spanning tree whose weight is the same as our MST, we have to remove an edge with lesser weight. The edge whose weight is the _second_ maximum is the best possible choice.

Lastly to simulate an edge replacement with the edge $(u,v)$, we compute $\ell=\operatorname{lca}(u,v)$ (using binary lifting), then merge both paths from $u\to\ell$ and $v\to\ell$ so that we consider all edges along the cycle we create by adding $(u,v)$, except $(u,v)$ itself.

**Time Complexity:** $\mathcal{O}(N\log N+M (\log N + \log M))$

```cpp
#include <bits/stdc++.h>
using namespace std;

#define int long long

// BeginCodeSnip{USACO Guide DSU}
namespace usaco_guide {
class DisjointSets {
  private:
	vector<int> parents;
	vector<int> sizes;

  public:
	DisjointSets(int size) : parents(size), sizes(size, 1) {
		for (int i = 0; i < size; i++) { parents[i] = i; }
	}

	/** @return the "representative" node in x's component */
	int find(int x) { return parents[x] == x ? x : (parents[x] = find(parents[x])); }

	/** @return whether the merge changed connectivity */
	bool unite(int x, int y) {
		int x_root = find(x);
		int y_root = find(y);
		if (x_root == y_root) { return false; }

		if (sizes[x_root] < sizes[y_root]) { swap(x_root, y_root); }
		sizes[x_root] += sizes[y_root];
		parents[y_root] = x_root;
		return true;
	}

	/** @return whether x and y are in the same connected component */
	bool connected(int x, int y) { return find(x) == find(y); }
};
};  // namespace usaco_guide
// EndCodeSnip

const int inf = 1e17;
const int N = 5e4 + 1;
const int K = 17;

// merging logic to keep {maximum value, maximum value that's strictly less than our
// maximum value}
pair<int, int> merge(pair<int, int> A, pair<int, int> B) {
	pair<int, int> C = {max(A.first, B.first), -inf};
	for (int x : {A.first, A.second, B.first, B.second})
		if (x != C.first) C.second = max(C.second, x);
	return C;
}

vector<int> mstadj[N];
int par[N][K], dep[N];
pair<int, int> wgt[N][K];
/* par[x][k] = node that's 2^k up from x
   wgt[x][k] = {max weight, max weight that's < max weight} along the path from x to the
   node 2^k above */

// DFS to compute the parent and depth of each node
void dfs(int x) {
	for (int y : mstadj[x])
		if (y != par[x][0]) {
			par[y][0] = x;
			dep[y] = 1 + dep[x];
			dfs(y);
		}
};

// calculate the lowest common ancestor of a & b using binary lifting
int lca(int a, int b) {
	if (dep[a] < dep[b]) swap(a, b);
	int dt = dep[a] - dep[b];
	for (int k = 0; k < K; k++)
		if (1 & (dt >> k)) a = par[a][k];
	if (a == b) return a;
	for (int k = K - 1; k >= 0; k--)
		if (par[a][k] != par[b][k]) a = par[a][k], b = par[b][k];
	return par[a][0];
};

// calculate {max weight, 2nd max weight} along the path from x going up h nodes
pair<int, int> liftup(int x, int h) {
	pair<int, int> cur = {-inf, -inf};
	for (int k = 0; k < K; k++)
		if (1 & (h >> k)) cur = merge(cur, wgt[x][k]), x = par[x][k];
	return cur;
};

// calculate {max weight, 2nd max weight} along the path from a to b
pair<int, int> calcpath(int a, int b) {
	int l = lca(a, b);
	pair<int, int> cur = {-inf, -inf};
	int ad = dep[a] - dep[l];
	int bd = dep[b] - dep[l];
	cur = merge(cur, liftup(a, ad));
	cur = merge(cur, liftup(b, bd));
	return cur;
};

int solve() {
	int n, m;
	cin >> n >> m;
	vector<array<int, 3>> edges(m), mst, other;
	for (auto &[w, u, v] : edges) cin >> u >> v >> w;

	// separate the edges into 'mst' and 'other' using Kruskal's algorithm + DSU
	usaco_guide::DisjointSets dsu(n + 1);
	sort(edges.begin(), edges.end());
	int mstw = 0;
	for (auto [w, u, v] : edges) {
		if (dsu.connected(u, v)) other.push_back({w, u, v});
		else {
			dsu.unite(u, v);
			mst.push_back({w, u, v});
			mstw += w;
		}
	}

	// return -1 if the graph is not connected
	if (mst.size() < n - 1) return -1;

	// perform DFS on the MST we've found to calculate the parent & depth of each node
	for (auto [w, u, v] : mst) {
		mstadj[u].push_back(v);
		mstadj[v].push_back(u);
	}

	dfs(1);

	// do binary lifting on the parents and {max weight, 2nd max weight} along paths
	par[1][0] = 1;
	for (auto [w, u, v] : mst) {
		if (par[u][0] == v) wgt[u][0] = {w, -inf};
		else wgt[v][0] = {w, -inf};
	}

	for (int k = 1; k < K; k++)
		for (int i = 1; i <= n; i++)
			par[i][k] = par[par[i][k - 1]][k - 1],
			wgt[i][k] = merge(wgt[i][k - 1], wgt[par[i][k - 1]][k - 1]);

	// iterate over all the edges not included in the MST, and try to do edge
	// replacements with them
	int best = inf;
	for (auto [w, u, v] : other) {
		auto path = calcpath(u, v);

		// case 1: we can remove the heaviest edge because its weight is distinct from
		// the weight of {u,v}
		if (path.first < w) {
			best = min(best, mstw - path.first + w);
			continue;
		}

		// case 2: we cannot, so we must remove the heaviest edge whose weight is less
		// than the weight of the heaviest edge
		if (path.second == -inf) continue;
		best = min(best, mstw - path.second + w);
	}

	return best == inf ? -1 : best;
}

int32_t main() {
	cin.tie(0)->sync_with_stdio(0);
	cout << solve() << '\n';
}
```
