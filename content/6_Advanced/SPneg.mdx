## Introduction

In [Shortest Paths](/gold/shortest-paths), we learned how to find
the shortest path on a graph with nonnegative edge weights. Now, we return to
this problem but extend our approach to graphs with negative weights.

In the previous module, our go-to approach for solving shortest path problems was
Dijkstra's algorithm. However, when we introduce negative weights, Dijkstra's algorithm
can fail because it assumes the shortest path to the closest unvisited vertex is
final once it is popped from the heap.

Below is an example of Dijkstra failing, reporting the shortest distance from $a$ to $c$
as $4$ instead of $2$.

<video width="960" height="720" controls>
	<source src="/animations/Dijkstra_fail.mp4" type="video/mp4"/>
</video>

It is worthwhile to note that while the code for Dijkstra's algorithm presented
[earlier](/gold/shortest-paths#mathcalomlog-n-implementation) will still give correct
results given no reachable negative cycles, it will no longer be bounded by $\mathcal{O}(N+M\log{N})$ where $N$ is the
number of vertices and $M$ is the number of edges.

In order to find paths on graphs with negative edge weights, we can use the
other algorithms mentioned in the Shortest Paths module, Bellman-Ford and
Floyd-Warshall.

## Example - Single-Source Shortest Path

<FocusProblem problem="bellSam" />

### Explanation

#### Negative Cycles

Before we try to compute the shortest path, we need to determine if a shortest
path even exists. A negative cycle is a cycle whose edge weights sum to a negative
number. If a negative cycle exists in a graph, any path which can reach that cycle
can traverse that cycle an arbitrarily large amount of times, making the path
length arbitrarily small.

Thus, for any path from $s$ to $v$, there are three possible answers:
- Impossible: no path exists from $s$ to $v$.
- $l$: a shortest path of finite length $l$ exists from $s$ to $v$.
- $-$Infinity: there is a negative cycle reachable along the path from $s$ to $v$.

#### Bellman-Ford

Since the graph is sparse ($M \ll N^2$), Bellman-Ford, introduced
[earlier](/gold/shortest-paths#Bellman-Ford), appears to be the natural choice.
After $N-1$ iterations, all finite shortest distances are correct, since the shortest
path with the most edges can have at most $N-1$ edges.

To detect paths with negative cycles, we can check if any edge can still be relaxed
after these $N-1$ iterations. If the distance between $s$ and any vertex changes,
it must be reachable from a negative cycle, since its apparent shortest path includes
more than $N-1$ edges. We can mark all vertices whose path length changed on the
last relaxation, and use BFS starting from every marked vertex to find all vertices
that are reachable from the negative cycles.

### Implementation

**Time Complexity:** $\mathcal{O}(N \cdot M)$

<CPPSection>

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
	int n, m, q, s;
	cin >> n >> m >> q >> s;

	while (!(n == 0 && m == 0 && q == 0 && s == 0)) {
		vector<vector<pair<int, int>>> adj(n);
		for (int i = 0; i < m; i++) {
			int u, v, w;
			cin >> u >> v >> w;
			adj[u].emplace_back(v, w);
		}

		// long long because a negative cycle can push distances below INT32_MIN
		vector<long long> dist(n, INT64_MAX);
		dist[s] = 0;

		for (int i = 0; i < n - 1; i++) {
			for (int u = 0; u < n; u++) {
				if (dist[u] == INT64_MAX) { continue; }
				for (auto &[v, w] : adj[u]) { dist[v] = min(dist[v], dist[u] + w); }
			}
		}

		queue<int> bfs_queue;

		// one more iteration to detect negative cycles on graph
		for (int u = 0; u < n; u++) {
			if (dist[u] == INT64_MAX) { continue; }
			for (auto &[v, w] : adj[u]) {
				// the relaxed vertices are reachable from a negative cycle
				if (dist[u] + w < dist[v]) { bfs_queue.push(v); }
			}
		}

		vector<bool> is_negative_inf(n, false);

		while (!bfs_queue.empty()) {
			int u = bfs_queue.front();
			bfs_queue.pop();
			// a vertex can be in the queue many times, only process it once
			if (is_negative_inf[u]) { continue; }
			is_negative_inf[u] = true;
			for (auto &[v, w] : adj[u]) {
				if (is_negative_inf[v]) { continue; }
				bfs_queue.push(v);
			}
		}

		for (int i = 0; i < q; i++) {
			int target;
			cin >> target;
			if (is_negative_inf[target]) {
				cout << "-Infinity" << '\n';
			} else if (dist[target] == INT64_MAX) {
				cout << "Impossible" << '\n';
			} else {
				cout << dist[target] << '\n';
			}
		}

		cin >> n >> m >> q >> s;
	}
}
```

import queue

n, m, q, s = map(int, input().split())
while True:
	if n == 0 and m == 0 and q == 0 and s == 0:
		break

	adj = [[] for _ in range(n)]
	for _ in range(m):
		u, v, w = map(int, input().split())
		adj[u].append((v, w))

	dist = [float("inf")] * n
	dist[s] = 0

	for i in range(n - 1):
		for u in range(n):
			if dist[u] == float("inf"):
				continue
			for v, w in adj[u]:
				dist[v] = min(dist[v], dist[u] + w)

	bfs_queue = queue.Queue()

	# one more iteration to detect negative cycles on graph
	for u in range(n):
		if dist[u] == float("inf"):
			continue
		for v, w in adj[u]:
			# the relaxed vertices are reachable from a negative cycle
			if dist[u] + w < dist[v]:
				bfs_queue.put(v)

	is_negative_inf = [False] * n
	while not bfs_queue.empty():
		u = bfs_queue.get()
		# a vertex can be in the queue many times, only process it once
		if is_negative_inf[u]:
			continue
		is_negative_inf[u] = True
		for v, w in adj[u]:
			if is_negative_inf[v]:
				continue
			bfs_queue.put(v)

	for _ in range(q):
		target = int(input())
		if is_negative_inf[target]:
			print("-Infinity")
		elif dist[target] == float("inf"):
			print("Impossible")
		else:
			print(dist[target])

	n, m, q, s = map(int, input().split())

## Example - All-Pairs Shortest Paths
<FocusProblem problem="floydSam" />

### Explanation

#### Floyd-Warshall

Since this problem asks for the shortest path between any arbitrary pair of vertices,
and $N$ is relatively small, Floyd-Warshall, also introduced [earlier](/gold/shortest-paths#Floyd-Warshall),
appears to be the natural choice. Similar to above, after $N$ iterations, all finite
distances are correct, since every vertex has been considered as a possible intermediary
vertex.

To detect paths with negative cycles, check all distances between a vertex and itself.
If this distance is negative, then this means that that vertex is part of a negative cycle
or can reach a negative cycle and vice versa. Thus, any path that can contain this vertex as an intermediary
is also part of a negative cycle or can reach a negative cycle.

For a path $(i, j)$, if path $(i,k)$ is finite and path $(k, j)$ is finite, and the distance between
$k$ and itself is negative, then path $(i, j)$ must have an arbitrarily small length.

### Implementation

**Time Complexity:** $\mathcal{O}(N^3)$

<LanguageSection>

<CPPSection>

```cpp
#include <bits/stdc++.h>

using namespace std;
using ll = long long;

const int MAX_N = 150;
// With negative cycles, distances can double at every step of Floyd-Warshall,
// so we don't let them go below this value to avoid overflow.
const ll NEG_INF = -1e18;
ll dist[MAX_N][MAX_N], bad[MAX_N][MAX_N];

int main() {
	int n, m, q;
	while (cin >> n >> m >> q) {
		for (int i = 0; i < n; i++) {
			for (int j = 0; j < n; j++) {
				dist[i][j] = (i == j ? 0 : INT_MAX);
				bad[i][j] = 0;
			}
		}

		for (int i = 0; i < m; i++) {
			int u, v, w;
			cin >> u >> v >> w;
			dist[u][v] = std::min(dist[u][v], (ll)w);
		}

		for (int k = 0; k < n; k++) {
			for (int i = 0; i < n; i++) {
				for (int j = 0; j < n; j++) {
					if (dist[i][k] != INT_MAX && dist[k][j] != INT_MAX) {
						dist[i][j] = std::min(dist[i][j], dist[i][k] + dist[k][j]);
						dist[i][j] = std::max(dist[i][j], NEG_INF);
					}
				}
			}
		}

		for (int k = 0; k < n; k++) {
			for (int i = 0; i < n; i++) {
				for (int j = 0; j < n; j++) {
					if (dist[i][k] != INT_MAX && dist[k][k] < 0 &&
					    dist[k][j] != INT_MAX) {
						bad[i][j] = 1;
					}
				}
			}
		}

		for (int i = 0; i < q; i++) {
			int u, v;
			cin >> u >> v;
			if (bad[u][v]) {
				cout << "-Infinity" << '\n';
			} else if (dist[u][v] == INT_MAX) {
				cout << "Impossible" << '\n';
			} else {
				cout << dist[u][v] << '\n';
			}
		}
		cout << '\n';
	}
}
```
