## Introduction

## Minimum Weight Independent Sets
The beauty of matroids lies in the fact that there is a very simple algorithm to find minimum weight independent sets of size $1 \leq k \leq r(M)$. The algorithm is as follows:

$$
\begin{align*}
&\textbf{sort } E \text{ by weight increasing} \\
&S \leftarrow \{\}\\
&\textbf{for } e \in E \\
&\qquad \textbf{if } S + e \in \mathcal{I} \\
&\qquad\qquad S \leftarrow S + e \\
&\qquad \textbf{if } |S| = k \\
&\qquad\qquad \textbf{return } S
&\end{align*}
$$

Note that Kruskal's algorithm is a special case of this algorithm on the graphic matroid, where the independence checks are done by a DSU.

To prove correctness, fix an ordering of the elements $e_1, e_2, \dots, e_n \in E$ so that $w(e_1) \leq w(e_2) \leq \dots \leq w(e_n)$. Let the elements picked by the greedy algorithm have indices $p_1 < p_2 < \dots < p_k$. We claim that for any other independent set of size $k$ with indices $q_1 < q_2 < \dots < q_k$, the following holds:

$$
\begin{gather*}
p_1 \leq q_1 \\
p_2 \leq q_2 \\
\vdots \\
p_k \leq q_k
\end{gather*}
$$

Suppose for the sake of contradiction that $p_i > q_i$ for some $1 \leq i \leq k$. Let $A = \{e_{p_1}, e_{p_2}, \dots, e_{p_{i - 1}}\}$ and $B = \{e_{q_1}, e_{q_2}, \dots, e_{q_i}\}$. By the exchange axiom, there exists $e \in B \setminus A$ such that $A + e \in \mathcal{I}$. This is an immediate contradiction, as $e$ should have been added to $S$.

## Second-Best Spanning Trees
<FocusProblem problem="sample" />

As we've discussed before, matroids provide a perspective to understand Kruskal's MST algorithm. It turns out that the theory of matroids can also be used to find second-best spanning trees. Formally, we're given a weighted undirected graph, and we want to find the best suboptimal (meaning non-minimum weight) spanning tree, or decide that all spanning trees are optimal (or that there aren't any at all).

One natural way to generate low-weight suboptimal spanning trees is to start off with an MST, then consider adding edges that _aren't_ in the MST. For each such edge $(u,v)$, if we add it to our MST, we create a cycle. To restore our tree, we remove the __highest__ weight edge along the path between $u$ and $v$ (in our original tree) subject to the constraint that the weight of the resulting spanning tree should be greater than the weight of our original MST. This constraint just means that sometimes we'll have to remove the _second_ highest weight edge along the path between $u$ and $v$.

The optimality of this algorithm follows from a general fact about weighted matroids: _Suppose we have a matroid that admits a sub-optimal weight basis. Let $B$ be a min weight basis. Then, there exists a second-min weight basis $B'$ such that $B'=B-x+y$ for some $x\in B$ and $y\notin B$._

The algorithm we've described iterates over $y\notin B$ (the edge $(u,v)$ we add), then determines the best possible $x\in B$ to remove in order to achieve the lowest possible suboptimal weight.

### Implementation
Our implementation starts by computing an MST of the given graph using Kruskal's algorithm. Then, we use binary lifting: for each node $x$ and each $k\in[0,17)$, we compute the maximum weight out of all edges going up $2^k$ nodes, the _second_ maximum weight (i.e. the greatest that's strictly less), and also the node that's $2^k$ up. If the max or second max don't exist, we use $-\infty$. This is because ideally, we'd like to remove the edge with the maximum weight. However if that results in a spanning tree whose weight is the same as our MST, we have to remove an edge with lesser weight. The edge whose weight is the _second_ maximum is the best possible choice.

Lastly to simulate an edge replacement with the edge $(u,v)$, we compute $\ell=\operatorname{lca}(u,v)$ (using binary lifting), then merge both paths from $u\to\ell$ and $v\to\ell$ so that we consider all edges along the cycle we create by adding $(u,v)$, except $(u,v)$ itself.

**Time Complexity:** $\mathcal{O}(N\log N+M\log NM)$

```cpp
#include <bits/stdc++.h>
using namespace std;

#define int long long

// BeginCodeSnip{USACO Guide DSU}
namespace usaco_guide {
	class DisjointSets {
	private:
		vector<int> parents;
		vector<int> sizes;

	public:
		DisjointSets(int size) : parents(size), sizes(size, 1) {
			for (int i = 0; i < size; i++) { parents[i] = i; }
		}

		/** @return the "representative" node in x's component */
		int find(int x) { return parents[x] == x ? x : (parents[x] = find(parents[x])); }

		/** @return whether the merge changed connectivity */
		bool unite(int x, int y) {
			int x_root = find(x);
			int y_root = find(y);
			if (x_root == y_root) { return false; }

			if (sizes[x_root] < sizes[y_root]) { swap(x_root, y_root); }
			sizes[x_root] += sizes[y_root];
			parents[y_root] = x_root;
			return true;
		}

		/** @return whether x and y are in the same connected component */
		bool connected(int x, int y) { return find(x) == find(y); }
	};
};
// EndCodeSnip

const int inf = 1e17;
const int N = 5e4 + 1;
const int K = 17;

// merging logic to keep {maximum value, maximum value that's strictly less than our maximum value}
pair<int, int> merge(pair<int, int> A, pair<int, int> B) {
	pair<int, int> C = {max(A.first, B.first), -inf};
	for(int x : {A.first, A.second, B.first, B.second})
		if(x != C.first) C.second = max(C.second, x);
	return C;
}

vector<int> mstadj[N];
int par[N][K], dep[N];
pair<int,int> wgt[N][K];
/* par[x][k] = node that's 2^k up from x
   wgt[x][k] = {max weight, max weight that's < max weight} along the path from x to the node 2^k above */ 

// DFS to compute the parent and depth of each node
void dfs(int x) {
	for(int y : mstadj[x]) if(y != par[x][0]) {
		par[y][0] = x;
		dep[y] = 1 + dep[x];
		dfs(y);
	}
};

// calculate the lowest common ancestor of a & b using binary lifting
int lca(int a, int b) {
	if(dep[a] < dep[b]) swap(a, b);
	int dt = dep[a] - dep[b];
	for(int k = 0; k < K; k++ ) if(1 & (dt >> k)) a = par[a][k];
	if(a == b) return a;
	for(int k = K-1; k >= 0; k--)
		if(par[a][k] != par[b][k])
			a = par[a][k], b = par[b][k];
	return par[a][0];
};

// calculate {max weight, 2nd max weight} along the path from x going up h nodes
pair<int, int> liftup(int x, int h) {
	pair<int, int> cur = {-inf, -inf};
	for(int k = 0; k < K; k++ ) if(1 & (h >> k))
		cur = merge(cur, wgt[x][k]),
		x = par[x][k];
	return cur;
};

// calculate {max weight, 2nd max weight} along the path from a to b
pair<int, int> calcpath(int a, int b) {
	int l = lca(a, b);
	pair<int, int> cur = {-inf, -inf};
	int ad = dep[a] - dep[l];
	int bd = dep[b] - dep[l];
	cur = merge(cur, liftup(a, ad));
	cur = merge(cur, liftup(b, bd));
	return cur;
};

int solve() {
	int n, m;
	cin >> n >> m;
	vector<array<int, 3>> edges(m), mst, other;
	for(auto&[w, u, v] : edges) cin >> u >> v >> w;

	// separate the edges into 'mst' and 'other' using Kruskal's algorithm + DSU
	usaco_guide::DisjointSets dsu(n+1);
	sort(edges.begin(), edges.end());
	int mstw = 0;
	for(auto[w, u, v] : edges) {
		if(dsu.connected(u, v)) other.push_back({w, u, v});
		else {
			dsu.unite(u, v);
			mst.push_back({w, u, v});
			mstw += w;
		}
	}

	// return -1 if the graph is not connected
	if(mst.size() < n-1) return -1;

	// perform DFS on the MST we've found to calculate the parent & depth of each node
	for(auto[w, u, v] : mst) {
		mstadj[u].push_back(v);
		mstadj[v].push_back(u);
	}

	dfs(1);

	// do binary lifting on the parents and {max weight, 2nd max weight} along paths
	par[1][0] = 1;
	for(auto[w, u, v] : mst) {
		if(par[u][0] == v) wgt[u][0] = {w, -inf};
		else wgt[v][0] = {w, -inf};
	}

	for(int k = 1; k < K; k++) for(int i = 1; i <= n; i++)
		par[i][k] = par[par[i][k-1]][k-1],
		wgt[i][k] = merge(wgt[i][k-1], wgt[par[i][k-1]][k-1]);

	// iterate over all the edges not included in the MST, and try to do edge replacements with them
	int best = inf;
	for(auto[w, u, v] : other) {
		auto path = calcpath(u, v);

		// case 1: we can remove the heaviest edge because its weight is distinct from the weight of {u,v}
		if(path.first < w) {
			best = min(best, mstw - path.first + w);
			continue;
		}

		// case 2: we cannot, so we must remove the heaviest edge whose weight is less than the weight of the heaviest edge
		if(path.second == -inf) continue;
		best = min(best, mstw - path.second + w);
	}

	return best == inf ? -1 : best;
}

int32_t main() {
	cin.tie(0)->sync_with_stdio(0);
	cout << solve() << '\n';
}
```
