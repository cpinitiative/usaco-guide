## Minimum Weight Independent Sets
The beauty of matroids lies in the fact that there is a very simple algorithm to find minimumm weight independent sets of size $1 \leq k \leq r(M)$. The algorithm is as follows:

```cpp
vector<T> S;
sort(E.begin(), E.end());
for (auto e : E) {
    if (check(S, e)) {
        S.push_back(e);
        if (S.size() == k) {
            return S;
        }
    }
}
```

Here $\text{check}(S, e)$ returns true iff $S + e$ is independent. 

Observe that Kruskal's algorithm is a special case of this algorithm. The proof of correctness generalizes very nicely. We proceed by showing that the following invariant holds: there exists a minimal weight independent set $T$ of size $k$ such that $S \subseteq T$.

Label the elements of $E$ by $e_1, e_2, \dots, e_n$ such that $w(e_1) \leq w(e_2) \leq \dots \leq w(e_n)$. Suppose that $S \cup \{e_i\}$ is independent, and $e_i$ is added to $S$. If $e_i \in T$, then we are immediately done. Otherwise, $e_i \notin T$. Observe that by construction $T \setminus S \subseteq \{e_{i + 1}, e_{i + 2}, \dots, e_n\}$. Now, consider two cases.

Firstly, suppose that $T + e_i$ is independent. Then, pick any $e_j \in T \setminus S$, and let $T' = T + e_i - e_j$. Since $j > i$, it follows that $w(T') \leq w(T)$, and $S + e_i$ is a subset of a minimal weight independent set $T'$ of size $k$. The second case where $T + e_i$ is dependent is similar. By [FILL THE LEMMA IN], there exists a unique circuit $C \subseteq T + e_i$. Furthermore, $S + e_i$ is independent, so there exists $e_j \in T \setminus S$ such that $e_j \in C$. Since $C$ is the unique circuit contained in $T + e_i$, it follows that $T' = T + e_i - e_j$ is independent. From here, the same logic as the first case applies.
