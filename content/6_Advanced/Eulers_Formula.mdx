## Introduction

A planar graph is a set of vertices and edges that can be drawn in a way where no two edges cross over each other. Often, is possible to make a graph planar simply be redrawing the edges.

![Non-Planar Graph](/nonplanar-image.png)

![Planar Graph](/planar-image.png)


Given a planar graph, we can apply Euler's formula $V - E + F = 2$ to relate the number of vertices ($V$), edges ($E$), and faces ($F$) of the graph.

The equation is related to the theorem that for any convex polyhedron, $V - E + F = 2$ will hold true, due to the fact that every convex polyhedron may be flattened into a planar graph.

This can be expanded to graphs that are not connected to incorporate connected components. To avoid overcounting the external face of the connected components, the equation subsequently becomes $V - E + F = C + 1$, where $C$ is the number of connected components.

## Example 1

Firstly, notice that the fence will create a planar graph, where every closed-off region (including the region that consists of everything outside the fences) counts as a face. Every time we combine two faces by adding a gate, the number of faces will decrease by $1$. Thus, the answer will just be the number of faces in the graph minus one.

As a reminder, Euler's Formula states that $f=e−v+2$. To count the number of edges, we only need to count the number of unique unit-length segments Farmer John places. Likewise, to count the number of vertices, we just need to count the number of unique positions Farmer John visited. This can easily be achieved using sets.

Once we calculate these values, we can simply plug them back into the equation and get our answer.

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve() {
	freopen("gates.in", "r", stdin);
	freopen("gates.out", "w", stdout);

	int n;
	cin >> n;
	string s;
	cin >> s;

	int x = 0, y = 0;

	set<array<int, 2>> vertices;
	set<array<int, 4>> edges;

	vertices.insert({x, y});

	for (int i = 0; i < n; i++) {
		array<int, 2> dir;

		if (s[i] == 'N') dir = {0, 1};
		else if (s[i] == 'S') dir = {0, -1};
		else if (s[i] == 'W') dir = {-1, 0};
		else dir = {1, 0};

		int nx = x + dir[0];
		int ny = y + dir[1];

		array<int, 2> u = {x, y};
		array<int, 2> v = {nx, ny};

		if (u > v) swap(u, v);

		edges.insert({u[0], u[1], v[0], v[1]});
		vertices.insert({nx, ny});

		x = nx;
		y = ny;
	}

	cout << edges.size() - vertices.size() + 1 << '\n';
}

int main() {
	ios_base::sync_with_stdio(false);
	cin.tie(nullptr);

	solve();
}
```
